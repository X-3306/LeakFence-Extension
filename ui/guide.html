AI prompt safety

Keep secrets out of AI chats

LeakFence Local pauses paste and submit actions on supported AI chats, checks the text locally, and blocks API keys, tokens, private keys, IDs, recovery phrases, and secrets you protected manually.

No server, no cloud scan

Exact secrets are stored as local HMAC fingerprints in your browser profile. Pattern Guard runs locally. Your secrets, fingerprints, and audit events are not sent to the developer.

How privacy is enforced

  • There is no remote scanning endpoint in the extension.
  • Prompt text is evaluated locally by the content script and background worker.
  • Protected exact secrets are converted into local HMAC fingerprints before storage.
  • Audit entries stay in chrome.storage.local and never include plaintext secrets.
  • The source code is public at github.com/X-3306/LeakFence-Extension.

Built-in detections

Pattern Guard can catch common OpenAI, GitHub, AWS, Google, Stripe and Slack keys, JWTs, private key blocks, recovery phrase contexts, IBANs, and PESEL numbers.

Honest limits

LeakFence helps stop accidental prompt leaks. It cannot protect you from malware, a malicious extension, a compromised browser profile, or an AI page that changes in a way the extension no longer observes.
